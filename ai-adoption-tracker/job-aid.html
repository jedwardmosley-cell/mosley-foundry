AI Adoption Follow-Through Tracker

Use this tracker to answer three questions about an AI rollout: are people doing the new behaviors, are the behaviors sticking, and are they improving results? Keep this page next to you while you work in the tracker.

Who uses it: managers, team leads, change leads Time per week: about 5 minutes per rollout Open it: double-click index.html in the app folder

Set up a rollout

Once per rollout
  1. Create the rolloutGo to Rollouts > New rollout. Enter the AI tool, the team, the sponsor, and the launch date.
  2. Add each expected behaviorOpen the rollout > Add behavior. Write one observable action and name one accountable owner.
  3. Set the weekly check-in datesPick the first check-in date and how many weeks to track. The tracker fills in every 7 days.
  4. Define the business outcomeAdd the measure, the baseline (today's number), and the target. Include the unit: %, min, hours.

Record the weekly check-in

Every week
  1. Open Check-insGo to Check-ins. Missing weeks are listed first, then the ones due this week.
  2. Choose what happenedSelect Used, Partly used, or Not used for that week.
  3. Add notes and evidenceNote what you saw. Evidence is optional: a report name, a link, or a short description.
  4. Update the measureIf you have this week's number, enter it. It becomes the "current" value on the dashboard.
  5. Log a barrier if you heard oneOpen "Log a possible barrier" in the same form. Then select Save.

What each status means and what to do

Read the dashboard
Missed 2+ weeks
Reported Not used for the two most recent completed weeks in a row. Do: talk with the owner, log the barrier, and bring it to the manager review.
Check-in missing
The last check-in date passed with nothing recorded. This is a data gap, not nonuse. Do: ask the owner for the check-in and record it. Past weeks stay open.
Watch
Last week was Partly used, or a single week of Not used. Do: ask what got in the way before it becomes a flag.
On track
Last week was Used. Do: keep checking in and recognize the progress.
Sustained
Used three or more weeks in a row. The behavior is sticking. Do: share what is working with other teams.
Not started Paused
No check-in date has arrived yet, or the behavior was paused or retired. Paused behaviors are left out of the totals.
✓ Used ½ Partly used ✕ Not used ? No check-in Upcoming

Key rule: Partly used never counts toward the two-week flag, and a missing check-in never counts as Not used. The tracker keeps "nobody reported" separate from "it did not happen."

Choosing a barrier type

When you hear a reason
TypeWhat you might hearA good first move
Skills"I'm not sure how to edit what it gives me."Short demo, a peer coach, or a one-page how-to
Time"Meetings are back to back. There's no slot to prep."Protect time on the calendar or remove another task
Access"I still don't have a license or login."Raise it with IT and set a date it will be fixed
Workflow design"It's on a separate screen, so I have to leave my queue."Change the process or system so the step fits the work
Willingness"I don't trust it after it got one wrong."Listen, share evidence, and involve the person in fixes
UnknownNothing yet, or mixed signalsHave a conversation, then change the type once it's clear

When a barrier is dealt with, select Mark resolved and write what was done. Resolved barriers stay in the history.

Run the manager review

Every 2 weeks, or as agreed
  1. Missed 2+ weeksPick a decision for each flagged behavior, such as coach the owner, remove a barrier, or escalate.
  2. Missing check-insDecide how to close each data gap.
  3. BarriersTick the ones that are resolved and note what happened.
  4. OutcomesCompare current values with the baseline and target. Note what you see.
  5. Sign offChoose On track, At risk, or Off track, set the next review date, and select Save review.

Then share it: Summary > Print / Save as PDF, or Copy as text for an email.

Write behaviors people can see

The most common mistake
Vague

"Embraces the new AI tool."

Observable

"Uses the AI draft as the starting point for every first reply to a complaint."

  • Start with an action verb: uses, reviews, saves, logs.
  • Say when or how often: every claim, before each meeting, by Friday.
  • Name one owner, not a team.
  • Ask yourself: could someone else confirm it happened?

Protect the data

Every 2 weeks
  • Data is saved in the browser on that computer only. Nothing is sent anywhere.
  • Go to Data > Download backup. Keep the file in a safe folder or shared drive. The tracker reminds you after 14 days.
  • To move to another computer, or to recover lost data, use Restore with your latest backup file.
  • Clearing browser history or site data can erase the tracker. Back up first.

Common questions

I forgot to record last week. Is it too late?
No. Click the week in the behavior's weekly record and record it now.
Why isn't a behavior flagged when it was Partly used twice?
Only Not used counts toward the flag. Partly used shows as Watch.
My data is gone.
Check that you're in the same browser on the same computer. If so, restore your latest backup from the Data page.
How do I bring in ProcessIQ opportunities?
Go to Import, download the template, fill it in, and upload it. Then select Create behavior for each row.
