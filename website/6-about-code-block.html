I'm Jason Mosley.

In second grade I taught my classmates cursive, because I'd already learned it at my last school. I got in trouble for it. It wasn't in the lesson plan that year.

They needed it. I had it. So I gave it.

I've been doing that my whole life, teaching people a skill before the system says they're ready for it. Today that skill is AI. I help teams use the tools they already have, build what's missing, and lead the change so it actually gets used.
